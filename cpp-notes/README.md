📚 C++ — Estudos de Lógica e Sistemas Embarcados

Repositório criado para organizar meus estudos de C++, com foco principalmente em lógica de programação, fundamentos da linguagem e desenvolvimento de sistemas embarcados.

A ideia é evoluir do básico ao avançado, praticando através de exercícios, pequenos projetos e aplicações voltadas para hardware.

🎯 Objetivos
Aprender e fortalecer a lógica de programação.
Aprender C++ desde os fundamentos.
Desenvolver boas práticas de programação.
Aprender estruturas de dados e algoritmos.
Entender conceitos de memória e programação de baixo nível.
Conhecer conceitos utilizados em sistemas embarcados.
Trabalhar com microcontroladores.
Aprender sobre sensores, atuadores e comunicação entre dispositivos.
Criar projetos práticos para consolidar os conhecimentos.
