# PlatformIO Projects

Coletânea de projetos com Arduino/PlatformIO e estudos de C++, reunidos em um único repositório. Cada pasta é um projeto independente (com seu próprio `platformio.ini`).

## Projetos

| Projeto | Descrição |
|---|---|
| [Analog-reader](Analog-reader) | Leitura de sinal analógico na entrada A0 exibida no Monitor Serial. |
| [Arduino-blinking-led](Arduino-blinking-led) | Laboratório de estudos com Arduino, sistemas embarcados e automação (CLP). |
| [Arduino-bottoms-use](Arduino-bottoms-use) | Uso de botões para enviar comandos e acionar funções no Arduino. |
| [Arduino-display](Arduino-display) | Exibição de números em display de 7 segmentos. |
| [Arduino-exam-tinkercad](Arduino-exam-tinkercad) | Simulação de semáforo (LEDs verde/amarelo/vermelho) no Tinkercad. |
| [Arduino-selector_switch](Arduino-selector_switch) | Chave seletora para escolher entre diferentes modos de funcionamento de um circuito. |
| [Arduino-serial-monitor](Arduino-serial-monitor) | Exemplos de uso do Monitor Serial da Arduino IDE. |
| [Arduino-traffic-light](Arduino-traffic-light) | Sinaleira com LED vermelho e branco. |
| [Arduino-with-IA](Arduino-with-IA) | Jogo de reflexo — medição de tempo de reação com Arduino Uno. |
| [Bottom-number-display](Bottom-number-display) | Contador configurável por botões, com limite definido pelo usuário e LED indicador de fim de contagem. |
| [contador-99](contador-99) | Contador digital de 0 a 99 em display de dois dígitos. |
| [cpp-notes](cpp-notes) | Estudos de C++: lógica de programação, fundamentos da linguagem e sistemas embarcados. |
| [Display-0-9](Display-0-9) | Controle de display de 7 segmentos exibindo dígitos de 0 a 9. |
| [lcd-keyboard](lcd-keyboard) | Entrada via teclado matricial exibida em display LCD 16x2. |
| [project-embedded-bomb](project-embedded-bomb) | Simulação de um sistema de "bomba" (timer/senha) com Arduino Uno. |
| [provamicrocontroladorbomba](provamicrocontroladorbomba) | Prova/simulação com teclado matricial, LCD, buzzer e LED (sistema de bomba). |
| [radiohead-creep-lcd](radiohead-creep-lcd) | Sequência de mensagens exibidas em display LCD 16x2 com intervalos de tempo. |
| [Sonar-HC](Sonar-HC) | Sensor ultrassônico HC-SR04 medindo distância e acionando um LED. |
| [tension-reader](tension-reader) | Leitura de tensão analógica (0–5V) na entrada A0, exibida em LCD 16x2. |
| [test1-microcontroller](test1-microcontroller) | Simulação acadêmica de bomba: entrada de dados, temporização e controle de estados. |
| [teste](teste) | Sensor ultrassônico HC-SR04 com LED indicador (projeto de teste). |

## Tecnologias

- Arduino Uno / microcontroladores AVR
- PlatformIO
- C++
