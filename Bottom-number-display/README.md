Modifique o exemplo do Contador até 99 para que seja possível definir até onde a contagem ocorrerá após pressionar o botão pré-existente no exemplo.

Para realizar esta definição adicione ao circuito original  do Contador até 99 mais 2 botões nos pinos digitais 0 (RX) e 1 (TX) do Arduino. Esses botões devem ser utilizados para incrementar ou decrementar uma variável cujo valor é o objetivo do contador. Enquanto é incrementado o valor deve ser mostrado nos displays, ficando limitado a 99.

Adicione também um LED ao pino 13 para que represente o fim da contagem.

O resultado da tarefa deve ser:

1. Ao iniciar a simulação os displays devem mostrar zero.

2. Neste estado pode-se definir o valor objetivo utilizando os botões.

3. Após a definição do valor, pressionar o botão pré-existente para iniciar a contagem, que deve ser mostrada nos displays.

4. Quando a contagem alcançar o valor objetivo, o LED deve acender, e o valor apresentado nos displays deve ser zero, voltando novamente ao estado inicial.
